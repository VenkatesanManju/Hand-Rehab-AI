# AI-Based Hand Rehabilitation Recovery Monitoring System
NLP course project: diary NLP (BiLSTM + attention), RNN/LSTM/GRU/BiLSTM comparison,
recovery-trend forecasting, and a MediaPipe exercise-form demo.

Full plan: `docs/PROJECT_PLAN.md`. Build scope: `SCOPE.md`. Agent rules: `AGENTS.md`.

## Setup
```bash
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m nltk.downloader punkt wordnet stopwords
```
